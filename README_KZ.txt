IT ИНФРАҚҰРЫЛЫМ САБАҒЫ — ТАПСЫРМАСЫ
Тіркелу, кіру және қолданушыларды TXT файлға сақтау

ІСКЕ ҚОСУ:
1. ZIP архивті бір бумаға толық шығарыңыз.
2. Компьютерде Node.js орнатылғанын тексеріңіз: https://nodejs.org
3. start.bat файлын екі рет басыңыз.
4. Бірінші іске қосқанда npm пакеттері автоматты орнатылады.
5. Браузерде http://localhost:3000 ашылады.

ҚОЛДАНУ:
1. «Тіркелу» бетіне кіріп, логин мен құпиясөзді енгізіңіз.
2. Тіркелу сәтті болса, сайт автоматты түрде «Кіру» бетіне ауысады.
3. Сол логин мен құпиясөзді қайта енгізіп, жүйеге кіріңіз.
4. Кірген соң жеке кабинет ашылады.

ДЕРЕКТЕРДІ САҚТАУ:
- Барлық тіркелген аккаунттар data/users.txt файлына сақталады.
- Әр қолданушы жеке JSON жолы ретінде жазылады.
- ID 0-ден басталып, автоматты түрде ретімен өседі.
- Логин, ID, тіркелген уақыты және passwordHash сақталады.
- Құпиясөздің өзін ашық мәтінде сақтау қауіпті. Сондықтан файлда bcrypt хэші сақталады.
- Кіру кезінде сервер енгізілген құпиясөзді хэшпен салыстырады.

ЕСКЕРТУ:
Бұл оқу тапсырмасына арналған жергілікті сервер. Интернетке жариялау үшін
HTTPS және тұрақты session store сияқты қосымша қауіпсіздік баптаулары қажет.
